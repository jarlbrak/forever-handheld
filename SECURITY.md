# Security policy

Forever Handheld is a World of Warcraft addon. It runs inside the game's Lua sandbox, makes no network
requests, and stores only per-character UI settings (`ForeverHandheldDB`).

## Reporting a problem

If you find something that could harm players, such as a way the addon could leak account, chat or
character data, or tooling in this repository that could expose a user's machine, please report it
privately through GitHub's
[private vulnerability reporting](https://github.com/jarlbrak/forever-handheld/security/advisories/new)
rather than a public issue.

Please include the version, what you observed, and steps to reproduce. You can expect an initial
response within a week.

## Supported versions

Only the latest release is supported.
