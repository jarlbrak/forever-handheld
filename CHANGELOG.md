# Changelog

Notable changes to Forever Handheld. Versions follow the toc `## Version`. The release workflow uses
the section for the tagged version as the release notes.

## 3.7.180

First public release. The addon was developed privately through 3.7.180 and is imported here as is.

- Controller dock mirroring ControllerForever's base, LT, RT and LT + RT layers with native icons.
- Contextual target HUD, passive conversation glance and activity feed.
- Handheld layouts for Settings, keybinding, edit mode, professions, collections, calendar, chat
  settings, tutorials and supported addon windows.
- Optional integrations for RXPGuides, Loreward, Questie, RareScanner and AutoGear.
- RXPGuides v4.11.36 compatibility patch that defers guide window geometry during combat.
